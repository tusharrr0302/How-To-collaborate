#1 bug

Empty task titles are accepted

Problem: Submitting spaces or blank titles creates ghost tasks on the board.

Acceptance Criteria: Validate with trim(), show visual error banner, keep focus on input. Suggested branch: fix/empty-title-validation.

#2 feature

Filter tasks by completion status

Problem: As tasks accumulate, users need to focus on remaining pending work or review finished items.

Acceptance Criteria: Segmented control with "All", "Pending", and "Completed" with updated badges. Suggested branch: feat/status-filters.

#3 feature

Add task search

Problem: Quickly locate tasks by keyword in title, description, or label.

Acceptance Criteria: Real-time filtering, clear button, informative zero-result state. Suggested branch: feat/task-search.

#4 bug

Task counts become incorrect after deletion

Problem: Deleting a completed or pending task should immediately recalculate statistics.

Acceptance Criteria: Task counters and progress bars synchronize after every deletion. Suggested branch: fix/counter-sync-on-delete.

#5 enhancement

Improve mobile responsiveness

Problem: Ensure buttons have 44px touch targets and layout cleanly folds on phones.

Acceptance Criteria: Responsive grid, no horizontal scroll, accessible buttons on mobile. Suggested branch: enhancement/mobile-layout.

#6 documentation

Improve local setup instructions

Problem: Beginners need clear step-by-step instructions for running without tooling or servers.

Acceptance Criteria: Document Python http.server, VS Code Live Server, and double-click opening. Suggested branch: docs/setup-instructions.

#7 enhancement

Add keyboard support and clearer focus indicators

Problem: Keyboard-only developers need visual focus rings and standard shortcuts.

Acceptance Criteria: Focus indicators with :focus-visible, Escape key modal closing, N/slash shortcuts. Suggested branch: a11y/keyboard-navigation.
